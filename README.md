## 🌟 Overview

**ShopSphere** is a full-stack e-commerce web application currently under development.

The project is being built to provide a modern online shopping experience where customers can browse products, search and filter items, manage their shopping cart, place orders, and track their purchases.

ShopSphere is also a portfolio project focused on developing practical skills in **Django backend development, REST API development, PostgreSQL database management, authentication, and e-commerce business logic**.

---

## 🔥 Planned Features

### 👤 Customer Features

* **🔐 User Authentication:** Registration, login, logout, and profile management.
* **🛍️ Product Browsing:** Browse products and view detailed product information.
* **🔍 Smart Search:** Search products by name and relevant keywords.
* **🏷️ Category & Price Filtering:** Filter products based on category and price range.
* **🛒 Shopping Cart:** Add, remove, and update products in the cart.
* **❤️ Wishlist:** Save products for future purchases.
* **📦 Checkout & Orders:** Place orders and manage delivery information.
* **📋 Order History:** View previous and current orders.
* **🚚 Order Tracking:** Track order status from placement to delivery.
* **⭐ Reviews & Ratings:** Share product feedback and ratings.

### 🛠️ Admin Features

* **📊 Admin Dashboard:** Manage and monitor the e-commerce platform.
* **📦 Product Management:** Add, update, and remove products.
* **🏷️ Category Management:** Create and manage product categories.
* **📋 Order Management:** View and update customer orders.
* **👥 User Management:** Manage registered users.
* **⭐ Review Management:** Monitor product reviews and ratings.
* **📈 Inventory Management:** Manage product stock and availability.
